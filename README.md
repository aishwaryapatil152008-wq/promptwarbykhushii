# 🌆 VAJRA – Smart City Explorer

### 🧭 Explore Your City. Discover More. Travel Smarter.

Welcome to **VAJRA – Smart City Explorer**, a web-based dashboard designed to help people explore cities, discover local places, experience culture, and navigate city life more easily.

## ✨ About the Project

VAJRA brings useful city information together in one place. It helps users explore landmarks, find food and cafés, learn about local history, and access useful city information through a simple and user-friendly interface.

📍 **Current Demo City:** Pune, Maharashtra, India 🇮🇳

## 🚀 Key Features

* 🗺️ **City Explorer Map** – Explore sample locations around the city.
* 🔍 **Smart Search** – Search for places, food, and landmarks.
* 🍽️ **Food & Cafés** – Discover local food spots and cafés.
* 🏛️ **History & Culture** – Explore the city's culture and heritage.
* 🛡️ **Safety Center** – Access safety-related information.
* 🚦 **Traffic & Weather** – View city-related traffic and weather information.
* 📊 **Interactive Dashboard** – Navigate city features from one place.
* 🎨 **Modern UI** – Clean, attractive, and easy-to-use design.
* 📱 **Responsive Design** – Designed to provide a convenient browsing experience across screen sizes.

> ⚠️ Some features or locations may use demo/sample data. Live information depends on the APIs and integrations implemented in the project.

## 🛠️ Technologies Used

* 🌐 **HTML5** – Web page structure
* 🎨 **CSS3** – Styling and responsive layout
* ⚡ **JavaScript** – Interactive functionality
* 🗺️ **Map Visualization** – City map and sample location markers

## 💻 How to Run the Project

1. 📥 Download or clone the project repository.
2. 📂 Open the project folder in Visual Studio Code.
3. 🔎 Check that all required files and images are present.
4. 🌐 Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
5. 🎉 Explore the VAJRA Smart City Explorer dashboard!
